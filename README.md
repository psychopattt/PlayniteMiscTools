# Misc Tools
A plugin for [Playnite](https://playnite.link/) that adds a few tools to manage your game library.

## Features
- Shows number of missing icons, covers and backgrounds
- Shows database and cache size
- Button to add a "Missing Media" tag to games missing any type of image
  - Setting to ignore some categories
- Button to add a "Large Media" tag to game database entries bigger than the size specified in the settings
- Button to cleanup game descriptions
   - Remove "&lt;img/&gt;" and "&lt;video&gt;" tags
   - Remove empty tags
   - Keep only what's after "About the Game" for Steam descriptions
   - Remove "&lt;p&gt;" tags from lists
   - Remove leading and trailing "&lt;br/&gt;"
   - Remove "&lt;br/&gt;" before and after titles and lists
   - Limit the number of consecutive "&lt;br/&gt;" to 2
   - Setting to enable/disable automatic cleanup when adding a game
- Button to remove all tags generated by this plugin
- Setting to enable/disable automatic cache clearing when exiting Playnite
